# 面试问答总览

## 文档目标

本文档用于基于项目架构分析与项目经验提炼结果，整理一组贴合真实项目背景的前端面试题、追问问题和参考回答。

## 内容来源

- 项目架构文档：待补充
- 项目经验文档：待补充

## 题目范围

- 技术栈基础题：待补充
- 项目结合题：待补充
- 架构与工程化题：待补充
- 追问题：待补充

## 回答要求

- 每道题都要补充“回答依据”和“参考回答”。
- 参考回答优先使用可直接口述的表达，不只列关键词。
- 如果某个事实未在前置文档中确认，要在回答中标注“待结合实际项目补充”。
- 回答中涉及亮点、难点、取舍时，优先引用 `docs/project-insights/` 中已有结论。

## 推荐使用方式

1. 先练 `frontend-interview-questions.md` 中的基础题和项目题，先读问题，再脱稿回答，最后对照参考回答补强。
2. 再练 `follow-up-questions.md` 中的追问题，重点练方案取舍、边界处理和复盘表达。
3. 每道题回答时尽量关联真实项目事实，不要背离前置文档自行发挥。

## 推荐阅读顺序

- `docs/interview-questions/frontend-interview-questions.md`
- `docs/interview-questions/follow-up-questions.md`
